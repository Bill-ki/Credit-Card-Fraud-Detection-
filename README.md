# Credit-Card-Fraud-Detection-
Here's a short description in the same style as the README:

This is a Machine learning project that flags suspicious credit card transactions. Built to show how to handle a real imbalanced classification problem, not just chase a high accuracy score.

Objective
This is to Compare Logistic Regression and Random Forest on a fraud detection task, and show why precision, recall, F1 score, and Average Precision matter more than accuracy when the thing you're trying to catch is rare.
